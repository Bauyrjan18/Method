Research Methodology Passport • Task 2

Карточка методологии исследования

Сравнительный анализ алгоритмов машинного обучения (Random Forest vs LightGBM) для детекции аномалий и DDoS-атак в реальном времени в ресурсоограниченных сетях IoT

Дисциплина: Методы научных исследований (IT)
GitHub-репозиторий: https://github.com/Bauyrjan18/Method
Целевой бенчмарк: CICIoT2023 Dataset

1. Тип исследования и обоснование

Тип исследования: Количественное экспериментальное исследование (Quantitative Experimental Research).
Обоснование выбора: Исследование направлено на объективную верификацию гипотез посредством контролируемого вычислительного эксперимента. Измеряются строго количественные зависимые переменные: метрики качества классификации (Macro F1-score, Precision, Recall), временные характеристики (Inference Latency в мс) и системные ресурсы (RAM в МБ). Качественные методы не обеспечивают статистической строгости при оценке компромисса (trade-off) между точностью и микросекундной задержкой инференса сетевых пакетов на периферийных IoT-шлюзах.

2. Формулировка гипотез

Исследовательский вопрос 1 (RQ1 — Точность классификации)

Нулевая гипотеза (H0,1): При классификации аномалий и DDoS-трафика алгоритм LightGBM не демонстрирует статистически значимого превосходства по F1-score по сравнению с Random Forest (F1LightGBM ≤ F1RandomForest).

Альтернативная гипотеза (H1,1): Алгоритм гистограммного бустинга LightGBM обеспечивает статистически значимо более высокий Macro F1-score по сравнению с Random Forest при обработке атак высокой интенсивности (F1LightGBM > F1RandomForest), достигая F1 ≥ 0.95.

Исследовательский вопрос 2 (RQ2 — Редукция признаков и ресурсоэффективность)

Нулевая гипотеза (H0,2): Редукция признакового пространства до топ-10 признаков не приводит к снижению задержки инференса на пакет и потребления RAM в LightGBM более эффективно, чем в Random Forest, либо вызывает недопустимую деградацию качества (F1 < 0.95).

Альтернативная гипотеза (H1,2): Сокращение пространства признаков до топ-10 уменьшает задержку инференса более чем на 30% и сокращает потребление RAM более чем на 25% в LightGBM по сравнению с Random Forest при сохранении порогового уровня F1 ≥ 0.95.

4. Метрики, Пороговые ограничения (Guardrails) и Baseline

  • Первичная метрика (Primary Metric): Macro F1-score (устойчивость детекции при дисбалансе классов) и Inference Latency на 1 образец (мс).
  • Пороговые метрики (Guardrail Metrics):
    • Минимальное качество классификации: F1 ≥ 0.95 (недопустимость пропуска атак).
    • Максимальный лимит оперативной памяти: Peak RAM ≤ 256.0 МБ (аппаратное ограничение edge-устройств).
    • Максимальная задержка на пакет: Latency ≤ 15.0 мс (предотвращение переполнения сетевых очередей).
    • Надежность конвейера: 0% сбоев (отсутствие необработанных исключений).
  • Контрольная группа / Бэйзлайн (Baseline): Классический ансамбль Random Forest (RF) на полном наборе признаков (Full Feature Set — 46 признаков) со стандартной конфигурацией (n_estimators=100, max_depth=15). Выступает общепринятым индустриальным эталоном точности и стабильности в IDS.
